## Nos projets

### [ripdvd](https://github.com/asblPixels/ripdvd) — ripper de DVD en un clic

Outil open source pour Linux et Windows qui convertit un DVD en MKV H.264,
avec chapitres et sous-titres conservés. Interface GTK4/libadwaita sur Linux,
tkinter sur Windows, propulsé par HandBrakeCLI.

`Python` · `GTK4` · `HandBrakeCLI`
